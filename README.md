# School Gang Battle — Prototype v2

Game browser 2D bergaya pixel-art, dibuat agar bisa dicoba dari HP Android dan dikembangkan menjadi APK nanti.

## Isi
- `index.html`, `style.css`, `game.js`
- 3 arena pilihan: depan sekolah, koperasi desa, kantor MBG
- Player, musuh dengan AI sederhana, HP, menang/kalah, kontrol sentuh dan keyboard
- Efek suara sintetis langsung dari kode (pukul, tendang, lompat, hit, menang, kalah, meme pendek, tombol), tanpa file sound eksternal
- Pengatur volume dan mute

## Cara mencoba
Buka `index.html` di browser yang mendukung JavaScript. Di Android, lebih mudah unggah folder ini ke repository GitHub lalu aktifkan **Settings → Pages → Deploy from a branch → main / root**.

## Catatan
Ini prototype awal, belum APK. Gambar karakter dan arena saat ini digambar dari bentuk pixel sederhana di canvas, belum sprite sheet final. Jangan unggah file ZIP sebagai satu file saja jika ingin GitHub Pages menjalankan situs; ekstrak ZIP lalu unggah isi foldernya ke repository.
